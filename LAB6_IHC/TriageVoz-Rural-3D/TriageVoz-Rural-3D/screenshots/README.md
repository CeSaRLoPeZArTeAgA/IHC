# Capturas requeridas

Esta carpeta debe contener capturas REALES de la aplicación ejecutándose localmente.
No se incluyen capturas prefabricadas porque deben demostrar tu ejecución.

Capturas recomendadas:

1. 01_constelacion_general.png
   - Vista completa de la espiral 3D con los 14 nodos.

2. 02_tooltip_nodo.png
   - Cursor sobre un nodo mostrando nombre, RF, categoría y resumen.

3. 03_zoom_conexiones.png
   - Zoom cercano donde se revelen conexiones causales/funcionales.

4. 04_todas_conexiones.png
   - Botón "Mostrar todas las conexiones" activado.

5. 05_chat_gemini.png
   - Chat funcionando con el nodo N08 Asistente TriageVoz y una respuesta real de Gemini.

6. 06_filtro_categoria.png
   - Filtro por categoría, por ejemplo "Inteligencia Artificial".

7. 07_experimento_temperatura.png (recomendado)
   - Panel de chat mostrando una de las pruebas con temperature 0.0, 0.5, 1.0 o 1.5.
